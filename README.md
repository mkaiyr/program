# Кафе Бистро — демонстрационный сайт

Статический демонстрационный сайт кафе: меню с фотографиями и аллергенами, поиск, корзина, оформление заказа, имитация оплаты, страница заказа и демо-админка.
Построен на чистых HTML, CSS и JavaScript (ES-модули), без сборки, сервера и базы данных. Рассчитан на публикацию через GitHub Pages.

> **Это демонстрация.** Заказы не принимаются, платежи не выполняются и не имитируют списание денег, настоящей авторизации нет.
> Все данные (корзина, заказы, вход в админку, доступность блюд) хранятся только в `localStorage` браузера посетителя. Контакты, цены и адрес кафе — условные.

## Что есть на сайте
- **Главная, меню, поиск, карточка блюда.** 30 блюд в 9 категориях, поиск с учётом склонений и «ё», состав и аллергены на уровне ингредиентов (14 групп), недоступные блюда помечены.
- **Корзина.** Количество, комментарий, расчёт доставки (500 ₸, бесплатно от 8 000 ₸, минимальный заказ для доставки 2 000 ₸).
- **Оформление заказа.** Доставка или самовывоз, проверка полей и телефона, три способа оплаты, вопрос об аллергии. Повторное нажатие не создаёт второй заказ; корзина очищается только после того, как заказ реально сохранён.
- **Имитация онлайн-оплаты.** Кнопки «успех» и «отказ», повтор и смена способа. Поля банковской карты не запрашиваются.
- **Страница заказа и список заказов.** Телефон, адрес и почта на публичных страницах скрыты (маскируются). Статусы условные.
- **Демо-карта доставки** (`track-demo.html`): карта Алматы (Leaflet + OpenStreetMap), дорожный маршрут от демо-точки кафе до тестовой точки и **виртуальный** «Демо-курьер», который едет по линии маршрута. Запуск, пауза, продолжение, сброс, повтор, выбор тестовой точки в списке или на карте. Метки «ДЕМО-РЕЖИМ», время и расстояние демонстрационные.
- **Демо-админка** (`docs/admin/`): вход одной кнопкой, панель показателей, заказы (поиск по номеру, фильтр по статусу, сортировка, смена статуса, отмена), доступность блюд. Изменения доступности сразу видны в меню сайта; «Луковые кольца» зафиксированы в исходном состоянии.

## Ограничения и предупреждения
- **Демо-карта.** GPS не используется и настоящий курьер не подключён: координаты считаются по заранее рассчитанному маршруту (`docs/data/demo-routes.json`, строится разово `tools/build_demo_routes.py`). Демо-режим не пишет в заказы, корзину, склад или хранилище и не обращается к серверам заказов. Единственные внешние обращения сайта — картинки карты с `tile.openstreetmap.org` на странице демо-карты; публичные серверы OpenStreetMap подходят только для лёгкого демо, для рабочего сайта нужен поставщик карт с договором. Тестовые точки — общественные места, не адреса клиентов.
- **Нет настоящих платежей и нет авторизации.** Вход в админку — флаг в `localStorage`; любой может выставить его сам. Админка не защищена.
- **`localStorage` не защищённое хранилище.** Данные доступны любому скрипту на этом адресе и самому пользователю, не шифруются, не передаются на сервер, не синхронизируются между браузерами и устройствами и пропадают при очистке данных сайта. В приватном режиме и при переполнении запись может не сработать — сайт покажет ошибку, а не потеряет заказ молча.
- **Не вводите настоящие персональные данные.** В тестах и примерах используются только выдуманные.
- Состав и аллергены условные, не подтверждены производителем.

## Структура
```
docs/            — сайт (его публикует GitHub Pages)
  index.html, menu.html, dish.html, cart.html, checkout.html, payment.html, order.html, orders.html, 404.html, .nojekyll
  track-demo.html — демо-отслеживание доставки на карте
  admin/         — login.html, index.html (панель), orders.html, menu.html
  assets/        — css, js (логика без DOM + страницы в js/pages), vendor/leaflet (BSD-2, без изменений), fonts (OFL), img (логотип, заглушка, dishes/ — фото WebP)
  data/          — menu.json, ingredients.json, settings.json, demo-routes.json (маршруты демо-карты)
registry/        — внутренний реестр лицензий фото (на сайте не показывается; публиковать только если решите сами)
tools/           — проверки и браузерные тесты
tests/js/        — автотесты логики
```
`styleguide.html` — служебная страница дизайн-системы: в навигации скрыта, поисковикам закрыта.

## Запуск на своём компьютере
```
python3 -m http.server 8080 --directory docs
```
Откройте http://localhost:8080/. Локально сайт в корне, на GitHub Pages — в подкаталоге `/<репозиторий>/`, поэтому все адреса относительные.
Чтобы повторить условия Pages, запустите `python3 tools/check_subpath.py` — он раздаёт сайт под `/kafe-bistro/`.

## Проверки
```
python3 tools/check_all.py            # все проверки
python3 tools/mutation_tests.py       # контрольные поломки: тесты обязаны их заметить (долго)
```
Нужен Python 3. Автотесты JS и браузерные тесты используют встроенные в macOS JavaScriptCore и WebKit (нужны Command Line Tools); на других системах эти части пропускаются.
Проверки: данные (включая маршруты карты), фотографии и реестр, пути, контраст, структура HTML, гигиена репозитория (секреты, локальные пути, внешние адреса), синтаксис и автотесты JS, раздача в подкаталоге, браузерные сценарии оформления, админки, демо-карты (реальные тайлы OSM; без сети проверка загрузки подложки пропускается с предупреждением) и итоговый аудит страниц на экранах 390, 768 и 1280 px.

## Фотографии и шрифты
У 24 из 30 блюд есть фото, у остальных шести (в том числе обоих соусов) — аккуратная заглушка. Фото взяты только с первоисточников с лицензией CC0, подтверждения лежат во внутреннем реестре; на сайте ссылок на источники нет. Фото соусов будут добавлены позже, требования к ним — `registry/SAUCE_PHOTO_REQUIREMENTS.md`; снятые фото хранятся в `registry/removed-photos/`. Шрифты Manrope и Playfair Display — SIL OFL 1.1, тексты лицензий в `docs/assets/fonts/`.

## Публикация через GitHub Pages (на будущее)
Репозиторий ещё не создан и ничего не загружено. Когда решите публиковать (будущий адрес репозитория — `https://github.com/mkaiyr/kafe-bistro`):
1. Создайте репозиторий и загрузите в него содержимое этой папки (убедитесь, что в нём нет личных файлов: `python3 tools/check_hygiene.py`).
2. На GitHub: Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка **/docs**.
3. Сайт откроется по адресу `https://mkaiyr.github.io/kafe-bistro/`. Первая публикация занимает несколько минут.
4. Откройте главную, меню, оформление заказа и `admin/login.html` и убедитесь, что картинки и стили загрузились (все пути относительные и проверены в подкаталоге).
Папку `registry/`, `tools/` и `tests/` Pages не публикует (публикуется только `docs/`), но они останутся видны в репозитории; перед загрузкой решите, нужны ли они там.
