# Внутренний реестр фотографий

Здесь хранятся сведения об источниках и лицензиях фотографий блюд. **На сайте они не показываются**: покупатель видит только изображение.
Папка лежит вне `docs/`, поэтому GitHub Pages её не публикует. Но репозиторий публичный, и файлы видны тем, кто открывает репозиторий на GitHub.
Не записывайте сюда ключи, личные данные и ссылки с токенами.

Файл `photo-licenses.json` ведётся автоматически и проверяется `tools/check_photos.py`. Запись о каждом изображении:

| Поле | Значение |
|---|---|
| `dish_id` | идентификатор блюда из `docs/data/menu.json` |
| `file` | имя файла в `docs/assets/img/dishes/` |
| `source_type` | `own` (своё фото) · `ai` (создано генерацией) · `stock` (свободный источник) |
| `source_name`, `source_url` | где получено (только для внутреннего контроля) |
| `license`, `license_url` | лицензия и ссылка на её текст; допускается только CC0 1.0 (коммерческое использование без указания автора) |
| `license_verification`, `license_evidence` | чем подтверждена лицензия: цитата со страницы самого снимка у первоисточника и контрольная сумма страницы либо данные API Commons для файла. Запись агрегатора доказательством не считается |
| `original_title`, `file_url` | исходное название файла и адрес, откуда скачан |
| `author` | автор, если известен |
| `retrieved_at` | дата получения и проверки (ГГГГ-ММ-ДД) |
| `original_sha256`, `file_sha256`, `thumb_sha256` | контрольные суммы исходного снимка и готовых файлов (защита от подмены и путаницы) |
| `processing` | как обработано: обрезка, размеры, коррекция |
| `method` | для `ai`: сервис, модель, идентификатор генерации, запрос; для `stock`: как найдено |
| `checked_by`, `notes` | кто проверил лицензию, замечания |

Изображения, лицензия которых требует указывать автора на странице, на сайт не попадают.
Блюда без подходящего фото перечислены в `without_photo` с причиной, отклонённые группы — в `rejected_groups`, замены второго раунда проверки лицензий — в `replaced_photos` и `round2_review`.
Допустимые источники: ISO Republic, Foodiesfeed, Negative Space, Wikimedia Commons (контролирует `tools/check_photos.py`).
